# Security Policy

## Reporting a vulnerability

Please report security issues privately to Jeffrey Gregory (https://github.com/jwm-dev).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/jwm-dev/mabe-mouser-sdk/issues

## Scope

This policy applies to the generated Jeffrey Gregory SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the MABe Viewer public API, generated by
Jeffrey Gregory. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
